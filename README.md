# 豚骨拉面小世界 🍜

一个可以玩的 3D 拉面小世界：一碗冒着热气的豚骨拉面摆在木桌上，点一点食材、长按拿起来吃掉它。

**在线玩：https://kristisally25396982-debug.github.io/ramen-world/**

## 怎么玩

- **拖动旋转 / 双指缩放**：换个角度看这碗面
- **点一点食材**：每一样都有介绍和冷知识
- **长按拿起，拖进右侧的“吃掉”圈**：松手就吃掉，也可以直接点「吃掉它 😋」
- **重新上一碗**：吃完了再来一碗
- **🧲 物理模式**：打开后食材会按物理规律动起来
- **🫨 摇一摇**：摇一摇碗
- **🥄 勺子 / 🥢 筷子**：换工具舀汤、夹面
- **🍲 汤少演示**：看汤变少是什么样子

## 碗里有什么

10 样可点食材：面条、叉烧、溏心蛋（味玉）、鱼板（鸣门卷）、海苔、玉米粒、葱花、青菜叶、木耳丝，另加一双筷子。

比如：溏心蛋水煮约 6 分半后冰镇、再腌一夜才有流心；鸣门卷的螺旋得名于德岛的鸣门漩涡；博多拉面讲究细面，煮 30 秒左右就要上桌，还能免费替玉加面。

场景里还有蒸汽、汤面涟漪、茶壶、纸巾盒、灯笼和暖光，面条带 Q 弹的软体形变效果。

## 技术

- 单文件网页：`index.html`，打开即玩
- Three.js r128 + cannon.js 0.6.2（物理引擎），均走 cdnjs CDN
- 手机竖屏已适配（窄屏下顶部提示不再被徽章遮住）

## 本地运行

直接用浏览器打开 `index.html` 即可；如果浏览器限制本地文件加载，建议起一个本地服务：

```bash
python3 -m http.server 8000
```

然后打开 http://localhost:8000

注意：Three.js 和 cannon.js 从 CDN 加载，**需要联网**才能打开，离线打不开。
